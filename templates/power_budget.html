Zinwave 5000 (UNItivity) — repeater-fed downlink power budget

UK Cel-Fi repeater defaults: GO G41/G43 per-channel max +12 dBm full (G41 unit cap +16 dBm UK); Quatra 4000e +16 dBm per channel. Idle ≈ full −12 dB LTE breathing. Edit per-carrier values to match your WAVE/commissioning readout.

Topology & commissioning

Hub→RU fiber loss. 1 dBo = 2 dB RF gain reduction (default 1 dBo → max gain 23 dB).

Service module ports & repeater → hub passive losses

Duplex coax from the repeater feeds an RF splitter (3 dB per branch). DL attenuator after the splitter; UL attenuator defaults to DL + 3 dB so PH Portal UL balance can fine-tune hub UL gain.

DAS DL service port

Signal path: Repeater (duplex) → coax → RF splitter [−3 dB DL] → DL attenuator → hub → fiber → RU. Hub DL input window −5 to +15 dBm. DL optical loss (dBo) reduces max fiber gain by 2 dB RF per 1 dBo. System Active DL Gain = min(effective max − Calc level, RU target sizing).

DAS UL service port

Signal path: RU → hub UL amp → UL attenuator → RF splitter [−3 dB UL] → coax (duplex) → repeater. Set UL attenuator in the passive loss table (defaults to DL + 3 dB). Trim net UL gain with PH Portal UL balance — less negative adds hub UL gain (default −15 dB).

Method (zinwave.txt)

Hub per-carrier = repeater − coax (duplex) − RF splitter DL branch − DL attenuator − patch. UL path shares coax and splitter (−3 dB UL branch) plus UL attenuator. System gain = target RU power − hub DL input (full load). With n>1 carrier, hub/RU totals are DL input comp power / composite power (linear sum in mW).

UK repeater power defaults & sources

Default per-carrier full/idle levels in the donor table are taken from Nextivity (Cel-Fi) UK/EMEA datasheets and guides, for licence-exempt repeaters under Ofcom IR2102. They are starting values — always confirm against your WAVE portal or field measurement before commissioning.
